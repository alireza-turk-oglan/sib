# پشتیبان‌گیری و بازیابی

- فرمت فایل: `.sibbak` شامل نسخه ساختار، تاریخ، تعداد رکوردها و هش SHA-256 دیتابیس. فایل خراب، ناقص یا متعلق به نسخه جدیدتر برنامه بازیابی نمی‌شود.
- **تهیه پشتیبان:** صفحه «پشتیبان‌گیری». فایل ابتدا موقت نوشته، بازخوانی و اعتبارسنجی و سپس نام‌گذاری می‌شود.
- **پشتیبان خودکار:** هنگام بستن برنامه (۷ نسخه آخر) در پوشه برنامه؛ قابل خاموش‌کردن.
- **بازیابی:** انتخاب فایل ← نمایش محتوا ← تأیید ← ساخت پشتیبان ایمنی از وضعیت فعلی (پوشه `safety-backups`) ← جایگزینی ← بازگشایی. تا آخرین لحظه دیتابیس فعلی دست‌نخورده است و در صورت خطا همان می‌ماند.
- پشتیبان‌ها رمزنگاری نیستند؛ فایل را در مکان امن نگه دارید.
- بررسی سلامت: دکمه «بررسی سلامت پایگاه داده» و بررسی خودکار هنگام اجرا.
