# تنظیم IPPanel و درگاه‌های پرداخت

## IPPanel (پیامک)
۱. در پنل IPPanel یک **پترن** برای کد تأیید بسازید؛ مثلاً «کد ورود شما: %code%». کد پترن را بردارید.
۲. در پنل مدیریت سایت ← تنظیمات ← IPPanel: کلید API، شماره ارسال‌کننده (فرمت `+983000505`)، کد پترن و نام متغیر (`code`).
۳. API استفاده‌شده: Edge API (`https://edge.ippanel.com/v1/api/send`). پیام‌های باشگاه مشتریان با روش webservice از همان خط ارسال می‌شود.
۴. خطاهای ارسال در «گزارش پیامک» پنل مدیریت ثبت می‌شود. برای پیامک تبلیغاتی، قوانین اپراتور (از جمله امکان لغو دریافت) را رعایت کنید؛ می‌توانید متن انتهایی ثابت (مثلاً «لغو ۱۱») تعریف کنید.

## زرین‌پال
- مرچنت‌کد را وارد و «فعال» را تیک بزنید. برای تست «Sandbox» را روشن کنید. مبلغ‌ها به تومان (`currency: IRT`) ارسال می‌شود.
- تأیید پرداخت همیشه سمت سرور با Verify رسمی انجام می‌شود (کد 100 یا 101).

## زیبال
- مرچنت را وارد کنید یا برای تست «حالت تست» (`merchant=zibal`). مبلغ به **ریال** (تومان × ۱۰) ارسال می‌شود؛ در Sandbox تأیید کنید.
- درگاه فعال را از همان صفحه عوض کنید؛ تغییر کد لازم نیست.

## امنیت پرداخت
اشتراک فقط پس از Verify موفق و فقط یک بار فعال می‌شود (قفل ردیف پرداخت)، مبلغ از پلن سمت سرور خوانده می‌شود و مبلغ ناهماهنگ رد می‌شود.
